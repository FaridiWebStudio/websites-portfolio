# Faridi Web Studio — The Web Edit

A responsive website collection built with HTML and CSS. No JavaScript, framework, build step, font downloads or external image dependencies.

## Open it on your computer

Extract the ZIP. Keep `index.html` and `style.css` in the same folder. Double-click `index.html` to preview the website in your browser.

## GitHub par live kaise karein

1. GitHub par **+ → New repository** kholen.
2. Repository ka naam `faridi-web-studio` rakhen, **Public** select karein, aur repository create karein. README initialize karna optional hai.
3. Empty repository mein **uploading an existing file** par click karein. Existing repository mein **Add file → Upload files** select karein.
4. Extracted folder se `index.html`, `style.css` aur optionally `README.md` upload karein. ZIP file upload nahi karni. `index.html` repository ke root mein hona chahiye, kisi extra folder ke andar nahi.
5. Changes commit karein. Agar GitHub pull request banata hai, usse merge karein taaki files `main` branch mein aa jaayen.
6. **Settings → Pages → Build and deployment** kholen.
7. **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** select karein, phir **Save** karein.
8. Deployment complete hone par Pages settings mein **Visit site** link milega. Address normally `https://YOUR-USERNAME.github.io/faridi-web-studio/` hoga. `YOUR-USERNAME` ko apne actual GitHub username se replace karein.

## Customize

- Brand name: `index.html` mein “Faridi Web Studio” aur “FARIDI” edit karein.
- Website destinations: har project ke `href` ko edit karein. Teen actual links pehle se added hain.
- Colors: `style.css` ke starting `:root` block mein `--lime`, `--blue`, `--pink` edit karein.
- Text and descriptions: `index.html` mein project titles aur paragraphs edit karein.
- Year: footer mein year manually update karein.

The project panels are original typographic covers, not screenshots of the linked websites. The page presents a collection and does not claim that Faridi Web Studio created the linked sites. All external links open in a new tab. There is no contact form or invented email address.
